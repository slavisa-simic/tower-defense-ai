# Art batch record

Copy to `Docs/Art/Batches/<batch-id>.md` for a requested batch. Remove irrelevant fields and mark checks honestly; this template is not evidence of production.

## Scope and source

- Batch ID, phase, date, requested outputs:
- Existing user authorization / requested replacement scope:
- Approved master path, revision and approval evidence:
- Other reference paths and role of each input:
- Tool used and returned metadata (model/seed only if exposed):
- Exact final prompt(s), including follow-up edits:
- Raw output paths, dimensions, SHA-256 hashes:
- Selected runtime export paths and source relationship:
- Any explicitly requested deterministic conversion, tool version and settings:

## Art and import contract

- Palette, lighting, outline and silhouette checks:
- Actual image dimensions, alpha verification on light/dark backgrounds:
- Logical frame size, world PPU or UI dimensions, world size:
- Sheet rows/columns/count, margins, gutters, ordering:
- Pivot and orientation; sub-sprite names:
- FPS, loop flag, discrete keys, clip/controller paths:
- Import filter/compression/mipmaps/wrap/NPOT/max-size/platform overrides:
- UI nine-slice borders and interaction states, if applicable:
- Deviations from approved reference and reasons:

## Review and integration

- Status: planned / candidate / approved / integrated / validated / rejected / superseded
- Approval evidence and selected revision:
- Modified prefab/scene/UXML/USS/presentation bindings:
- Preserved gameplay components, GUIDs, root/footprint and state owners:
- Replacement reason and previous revision/rollback path:
- Compilation result, Console errors/warnings and disposition:
- Exact tests run and saved result paths:
- Play Mode visual checks, resolutions, screenshots:
- Checks not run and real blockers:
